# SmartBudgetManagger
What It Does?
SmartBudget Manager is a simple personal finance tool built in Microsoft Excel. It allows
users to track their monthly income and expenses, organize spending by category, keep an
eye on total balances, and receive instant visual alerts whenever expenses exceed the set
budget limit.

What You Need?
Software: Microsoft Excel (2016, 2019, 2021, Microsoft 365, or any compatible
spreadsheet program).
System: Windows or macOS computer.
Skills Required: Basic computer literacy (no advanced Excel skills required).

The Three Worksheets
Dashboard: Provides an executive summary of your money. It shows total income, total
expenses, net balance, expense breakdown charts, and budget status warnings.
Transactions: The main log table where you enter each income or expense item with its
date, description, type, category, and amount.
Categories: Contains predefined spending categories (such as Food, Transport, Rent,
Health, and Education) and their assigned monthly spending limits.

Getting Started
Open the File: Download and open SmartBudget_Manager.xlsx in Microsoft Excel. Click
Enable Editing if a safety bar appears at the top.
Set Budget Limits: Navigate to the Categories worksheet and review or adjust the target
budget amounts for each category.

Record Transactions: Go to the Transactions worksheet and type in your daily financial
records (income or expenses).
Monitor Financial Status: Open the Dashboard worksheet anytime to check your updated
total balance, pie charts, and budget warnings.
